# Project Knowledge Vault

Auto-managed by Claude Code knowledge graph hooks.
Canonical files live HERE (in the repo, versioned with code).
Obsidian sees them via `/mnt/d/Obsidian/KnowledgeHub/projects/<slug>/`
(Windows junction for /mnt drives, rsync mirror for WSL-native repos).

This directory contains project-scoped nodes:
- `decision/` — Architectural decisions (ADR-style)
- `episode/` — Session histories with outcomes
- `concept/` — Project-specific terminology
